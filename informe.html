Laboratorio #3.1:

Objetivos:
  1. Explicar qué es MCP y qué problema resuelve.
  2. Configurar un servidor MCP desde el archivo de configuración (mcp.json, .mcp.json) en distintos asistentes de IA.
  3. Verificar que el asistente detecta las herramientas (tools) que expone el servidor.
  4. Usar Playwright MCP para que el agente explore un sitio web real: navegar, llenar formularios, capturar el DOM.
  5. Generar pruebas E2E a partir de criterios de aceptación, con selectores y mensajes reales extraídos del sitio (no inventados).
  6. Ejecutar las pruebas generadas y cerrar el ciclo: criterio → exploración → test → verde.
